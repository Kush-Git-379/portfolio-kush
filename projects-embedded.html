Simulation & Comparison of Cryptography Techniques for Lightweight Systems

A comparative simulation study of four cryptographic algorithms — AES, DES, ECC, and ASCON — evaluated for suitability in lightweight embedded systems. The study benchmarks each algorithm across key metrics: encryption/decryption speed, key size, memory footprint, and energy consumption on resource-constrained hardware profiles. ASCON, the NIST-selected lightweight cryptography standard, is evaluated against traditional algorithms to quantify its advantages for IoT and embedded use cases. Simulation conducted using Python with custom benchmarking scripts.

IoT · Security ESP32

AES & ASCON Implementation on ESP32 via MQTT with Python Decryption

End-to-end implementation of AES and ASCON encryption on an ESP32 microcontroller, transmitting encrypted payloads over MQTT to a broker, with a Python-based subscriber performing decryption on the host machine. Demonstrates a practical IoT security pipeline — from sensor data encryption at the edge to secure cloud delivery. The project validates the feasibility of ASCON on constrained hardware and benchmarks its performance against AES in a real communication scenario.

Computer Architecture gem5

Cache Analysis of Matrix Multiplication & AES Encryption Benchmarks using gem5

Architectural simulation and cache performance analysis using the gem5 simulator. Two workloads were benchmarked: a matrix multiplication routine (compute-bound) and AES encryption (memory-access-intensive). Analysis covers L1/L2 cache hit rates, miss penalties, memory bandwidth utilization, and the effect of cache size and associativity on performance. Results provide insight into how cryptographic workloads behave differently from standard compute benchmarks at the microarchitecture level.

04
FPGA Digital Design

FPGA Projects — Fastest Finger First Game & Wallace Tree Multiplier

Two digital design projects implemented on FPGA using Verilog HDL. The Fastest Finger First (FFF) game detects the first button press among multiple players with microsecond precision, using finite state machines and debounce logic. The Wallace Tree Multiplier implements a high-speed parallel multiplier architecture using carry-save adders for reduced propagation delay compared to standard array multipliers — demonstrating understanding of combinational optimization and hardware arithmetic.

Log Analytics & Alert Mail System Automation

Automated system monitoring and alerting pipeline built with Bash and Python on Ubuntu. The system parses system and application logs, detects anomalies and critical events using pattern matching and threshold rules, and triggers automated email alerts to administrators. Designed for reliability in headless server environments, with cron-based scheduling and modular script architecture for easy extension to new log sources.
