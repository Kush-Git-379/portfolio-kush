Data Science Finance

Portfolio Analysis using Python

A financial portfolio analysis tool built in Python for evaluating multi-asset investment portfolios. The project covers asset allocation modeling, return calculation, risk metrics (standard deviation, Sharpe ratio, beta), and portfolio optimization using Modern Portfolio Theory. Includes visualization of the efficient frontier, correlation heatmaps, and historical performance charts. Designed as both an analytical and educational tool for understanding risk-return tradeoffs.

Student Management System

A full-featured student management application built with Python and MySQL. The system supports complete CRUD operations — creating, reading, updating, and deleting student records — with a menu-driven CLI interface. Features include grade management, attendance tracking, search and filter capabilities, and data export. Built with a normalized relational database schema and parameterized queries to prevent SQL injection.
